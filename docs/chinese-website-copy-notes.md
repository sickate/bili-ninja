# 中文官网首页文案说明

## 改写重点

原首页用了较多抽象口号、刻意断句和拟人化表达，例如“有问题，一起把它说清楚”，读者不容易从中判断 Instap 提供什么服务、产品能做什么、联系时应准备哪些信息。新版直接说明软件与硬件定制设计开发，并以需求梳理、原型等具体工作介绍服务；Bili Ninja 部分说明其 Chrome 侧栏形态、保存有声 MP4，以及将同一 BV 内多个分 P 的音频按顺序合并为 M4A 的用途。

措辞以具体对象、操作和结果为主，避免承诺未核实的客户案例、性能、兼容范围、报价、周期或交付结果。产品卡片用于说明使用场景，不表示卡片所列作品均已逐条完成导出实测；同时说明封面和作品归属原作者，并引导读者查看产品页。首页安装入口链接至现有安装教程。

## 参考的官方中文工具网站

- [Snipaste 官方中文网站](https://zh.snipaste.com/)：直接介绍截图与贴图用途，并用 F1 截图、F3 贴图说明基本操作。
- [PixPin 官方网站](https://pixpin.cn/)：以功能名称和用途组织介绍，说明本地文字识别，并提供下载和教程入口。
- [uTools 官方网站](https://www.u-tools.cn/index.html)：围绕用户操作及其结果说明工具用途和插件能力。

这些网站仅作为表达方式的参考；本页没有照搬其话术，也没有把调研过程写入产品介绍。

## 可供后续统一的文案建议

- 共享页脚可考虑把“把具体的需求，做成好用的产品。”改成对服务范围的直接说明，例如“软件与硬件定制设计开发”。这是建议，本次未修改模板。
- 首页 SEO 描述可考虑使用“Instap 提供软件与硬件定制设计开发，并开发 Bili Ninja Chrome 侧栏工具，可保存 B 站有声 MP4，或将同一 BV 内多个分 P 的音频按顺序合并为 M4A。”实际长度与搜索展示效果应在模板维护时一并核对。本次未修改共享模板或构建文件。
