## 验收标准

- 单 P M4A 含一个 AAC 音轨；MP4 含 H.264 与 AAC 两轨；完整解码无错误。多 P M4A 总时长与所选分 P 一致（允许编码帧级舍入），完整解码无错误。
- 实际浏览器证据与保存文件校验分别记录，不把截图、生成测试媒体或离线检查写成完整真实流程通过。
- 截图无凭据、账号资料、私密路径；图片有准确 alt 与说明，手机端不横向溢出；ZIP 内容、版本、大小及 SHA-256 与现有分发一致。
- 主 Agent 审阅 diff；本地测试与官网校验通过；远端 CI 与线上结果分开报告。

## 部署与回退

沿用 docs/website-deployment.md 及 scripts/deploy-website.py；不调整 DNS、证书、其他服务或扩展权限。发布前记录 current，使用已提交推送的干净工作区 stage 后 activate；线上验证失败时 rollback 到原 current 对应版本并复验。教程修改不需要提升扩展版本，扩展 ZIP 字节应保持一致。未获得设备或网络条件的项目保留待验收状态。
