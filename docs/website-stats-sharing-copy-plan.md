# 官网公开统计、分享功能和中文首页改写

日期：2026-11-15，Asia/Shanghai。

## 目标、范围与方案

1. 官网提供可直接查看的公开下载请求统计页，并从产品页及页脚进入。用户已选择公开汇总数据：只发布按北京时间日期和固定渠道分组的汇总计数及更新时间，不发布原始日志、任意UTM值、IP、UA或访客资料。非QA GET200为主要观察指标，206、失败和QA分开；不称人数、安装量或完整下载量。没有数据与尚未加载必须区分，不以假数据填充。
2. 继续使用maru/Nginx静态官网，周期任务每5分钟从已有私有轮转日志生成受限字段的JSON，原子写入站点根目录外的公开汇总目录。通过精确Nginx路径提供该JSON，保留发布切换时的持续更新。记录启用起点和滚动保留窗口；显示生成失败/陈旧状态。原始统计不变。
3. 产品页新增分享按钮，按X、小红书、微博、微信生成可编辑文案与固定渠道UTM链接。X/微博提供由访客点击的发帖窗口，最终由访客确认发布。小红书提供笔记标题/正文复制及保存插件截图入口；微信提供复制文案/链接及本地生成二维码；支持时提供系统分享。分享不自动发帖，不接账号、不读取凭据、不引入远端跟踪SDK。平台能力未证实则保留通用复制功能，不假称直发成功。
4. 首页整体改写，保留Instap软件/硬件定制开发和Bili Ninja产品事实。中文以具体名词、动作和使用场景为主：说清做什么、能解决什么、如何开始；去掉硬译式口号、刻意断句和英文装饰性文案。不捏造客户、使用量、兼容性、性能及导出验收。统一页脚和首页搜索描述，必要时顺带修正产品分享区域文案。
5. 保留现有截图与产品功能、下载包v1.2.1及SHA；本轮不修改扩展、DNS、证书和其他站点。只更新官网独立发布、www配置与本统计任务。

## 调研与内容准则

参考官方中文工具站Snipaste（https://zh.snipaste.com/）、PixPin（https://pixpin.cn/）与uTools（https://www.u-tools.cn/index.html），提取“用途—操作—结果—入口”的表达方法，不照搬口号或以少数样本概括所有中文网站。分享依据X官方Web Intents（https://docs.x.com/x-for-websites/web-intents/overview）、小红书官方JS SDK（https://agora.xiaohongshu.com/doc/js）。小红书明确不再自动填标题/文案，采用复制笔记材料。微信/微博官方文档部分不可读取，不把未核实的接口当作可用保证；优先通用文本、二维码，实际验证composer链接。

## 验收、部署与回退

- 主Agent独立检查公开JSON字段与渠道白名单、无原始日志/任意来源值；用独立样例检验日期边界、QA隔离、失败/206及空数据、异常和原子更新；确认Nginx精确路由仅公开汇总文件、其他路径不可访问。
- 分享核验各渠道链接、UTM覆盖、复制/编辑和权限失败回退、本地二维码实际内容、无远程SDK/传图、键盘可用、移动布局及状态提示；只打开composer不发送内容。二维码用标准工具独立解码核验。首页逐句评审，检查标题/SEO与页面事实一致。
- 运行相关新增测试、npm test、官网构建和verify；不为静态文案编写逐字镜像测试。ZIP版本/字节/hash保持一致。浏览器确认首页、产品分享区和统计页；模拟视口不称真实手机。
- Review通过后提交推送，从已推送干净提交构建。先核实生产current及www配置、任务/目录缺失状态，备份将修改的独立文件；安装已审统计生成器/周期任务，真实生成JSON；nginx -t通过后reload，仅改www。启用timer后验证一次真实周期更新、失败状态和权限。
- 按仓库stage/activate发布官网，验证普通公网HTTPS五页加统计页及资源、公开JSON、下载包、分享元信息及其他站点状态；查询远端CI，有无记录如实区分。
- 回退官网到本次发布前current；统计任务可stop/disable并恢复任务文件/www配置备份，nginx -t通过后reload，保留私有原始日志。不得清空历史统计或删除其他站点文件。若前端回退，统计独立路由可按备份恢复。
