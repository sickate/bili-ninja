需要电脑和 Chrome 116 或更新版本。本页介绍官网 ZIP 的手动安装方式。Windows 和 macOS 的系统解压界面略有不同；下方步骤图为操作示意，并非实际安装截图。

从官网 ZIP 安装

下载包只包含扩展文件。安装前请把它解压到一个准备长期保留的位置；不要安装后再移动或删除该文件夹，否则 Chrome 可能无法继续加载扩展。

  1. 下载 ZIP 并解压

    Windows：在下载的 ZIP 上点击右键，选择“全部提取…”，确认目标位置并提取。
    macOS：在 Finder 中双击 ZIP，系统归档工具会在旁边解压出文件夹。

    不同系统或解压工具可能会多套一层文件夹。打开解压结果，逐层查看，找到直接含有 manifest.json 的那一层；记住这个文件夹的位置。

  2. 打开 Chrome 扩展程序页面

    复制下面的地址，在 Chrome 地址栏粘贴并按回车：

    chrome://extensions

  3. 打开开发者模式

    在扩展程序页面右上角打开“开发者模式”。页面会显示加载本地扩展的操作按钮。

  4. 选择“加载已解压的扩展程序”

    点击该按钮，在系统文件选择窗口中定位到刚才解压的位置。

  5. 选择 manifest.json 所在目录

    选择直接包含 manifest.json 的文件夹，然后确认。不要选择 ZIP 文件，也不要选择它的上一级目录。若系统解压后出现多层目录，继续打开，直到看到 manifest.json 再选择该层。

    官网 ZIP 与 GitHub 源码的目录不同：官网 ZIP 选择其中直接含 manifest.json 的解压目录；若安装 GitHub 源码，则选择仓库里的 extension/ 目录。

  6. 固定扩展并开始使用

    打开 Chrome 工具栏的扩展程序菜单，在 Bili Ninja 旁点击固定图钉。打开一个可以正常播放的普通 Bilibili BV 视频页，点击彩色的 Bili Ninja 图标即可在侧边栏操作。非 Bilibili 页面或首页等不支持页面不会启动导出。

首次使用

视频页和侧边栏保持打开。选择“仅音频”可勾选同一 BV 稿件中的一个或多个分 P，按原顺序导出合并后的 M4A；选择“完整视频”可为一个分 P 导出带声音的 MP4。无需等待视频播放完毕。导出完成后按 Chrome 提示选择保存位置。

音频为原始 AAC 音轨封装成 M4A，不直接输出 MP3；多 P 合并只支持同一 BV 下所选分 P，音轨参数不兼容时无法合并。视频每次处理一个分 P，输出 H.264 + AAC 的 MP4。清晰度取决于账号当前可播放权限，不绕过付费试看或 DRM。单条画面流或音频流上限 512 MB，单次导出合计上限 1 GB；处理时保持视频页和侧边栏打开。

常见问题

Chrome 提示找不到 manifest.json 或无法加载扩展，怎么办？

通常是选错了目录。重新检查解压后的目录层级，选择直接含有 manifest.json 的那一层。官网 ZIP 不是 GitHub 源码目录，不要照着源码教程选择 extension/。

重启 Chrome 后扩展失效，或提示扩展文件无法读取？

确认原安装文件夹仍在原位置且文件未被删除，然后在 chrome://extensions 检查扩展状态并点击重新加载。不要移动已加载的文件夹；如目录已变动，可从新位置重新加载。

工具栏里看不到 Bili Ninja？

打开 Chrome 扩展程序菜单，找到 Bili Ninja 并固定到工具栏。请在普通 Bilibili BV 视频页使用；其他网站上的图标不可用。

没有想要的清晰度，或导出失败？

清晰度由当前账号和视频实际可播放的 H.264 资源决定。先在原视频页确认可正常播放，再刷新页面并重新打开侧边栏。确认视频页和侧边栏保持打开；超出大小上限时可尝试降低清晰度，音频可减少所选分 P。

Chrome 更新时要求接受新权限，要怎么处理？

Bili Ninja 使用 Chrome 侧边栏、识别 Bilibili 页面和保存导出文件所需的权限，并仅访问 Bilibili 及其媒体 CDN。安装或更新时若 Chrome 显示权限说明，请先查看提示；确认继续使用后接受权限，扩展才能按说明工作。权限用途见隐私说明。

手动更新

  1. 从本页下载新版 ZIP，并解压到临时位置。
  2. 将新版扩展文件解压到原安装目录，并覆盖其中同名文件；保持原目录位置不变，确保 manifest.json 仍直接位于该目录中。
  3. 打开 chrome://extensions，找到 Bili Ninja，点击卡片上的重新加载图标。
  4. 回到 Bilibili 视频页，重新打开扩展侧边栏。

如更新后无法加载，确认 Chrome 加载的目录仍然存在且直接包含 manifest.json，然后重新加载该扩展。版本和更新记录见更新日志。
